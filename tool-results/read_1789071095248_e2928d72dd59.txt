     7→     7→## Project Overview
     8→     8→
     9→     9→A production-ready, free/low-cost business lead generation platform built on Next.js 16
    10→    10→+ Prisma (SQLite) + socket.io mini-service worker. Discovers REAL public business leads
    11→    11→from permitted sources (OpenStreetMap Overpass API, public website contact pages) — no
    12→    12→mock data, no dummy records.
    13→    13→
    14→    14→### Architecture
    15→    15→- **Frontend**: Single-page app at `/` (App Router) with client-side section navigation.
    16→    16→  Sections: Dashboard, Find Leads, Campaigns, Leads, Exports, Analytics, Sources,
    17→    17→  Suppression List, Settings.
    18→    18→- **API**: Next.js API routes under `/src/app/api/*` (REST).
    19→    19→- **Worker / Realtime**: Mini-service on port 3003 (`mini-services/lead-worker`)
    20→    20→  running socket.io + background discovery pipeline. Campaigns execute here.
    21→    21→- **Database**: Prisma + SQLite at `db/custom.db`.
    22→    22→- **Real sources**: OpenStreetMap Overpass API (business POIs with phones/websites),
    23→    23→  Nominatim (geocoding), public website contact-page scraping (SSRF-protected).
    24→    24→
    25→    25→### Tech Stack
    26→    26→Next.js 16, TypeScript, Tailwind CSS 4, shadcn/ui (New York), Prisma, socket.io,
    27→    27→cheerio (HTML parsing), libphonenumber-js (E.164), xlsx (export), recharts (analytics).
    28→    28→
    29→    29→### Key Constraints
    30→    30→- Only `/` route is user-visible (SPA with internal nav).
    31→    31→- API requests must be relative paths; cross-port via `?XTransformPort=3003`.
    32→    32→- z-ai-web-dev-sdk only in backend.
    33→    33→- SSRF protection on all outbound website fetches.
    34→    34→- NO mock/dummy leads. Every lead from a real permitted source.
